📖 Panduan Singkat

      
Cara memakai tool ini untuk membuat draf konten dengan cepat.


      

        
1. Mulai

        

          Isi nama produk dan target audience, pilih gaya konten, lalu klik Generate. Makin jelas deskripsi produknya, makin berguna hasilnya.
        

      


      

        
2. Hook 3 Detik

        

          Orang memutuskan lanjut nonton atau swipe di 3 detik pertama. Pakai rasa penasaran, atau langsung sebut masalah yang dialami audience.
        

      


      

        
3. Prompt Video AI

        

          Salin prompt-nya, lalu tempel ke tools video AI seperti Kling, Luma, Runway, atau Veo untuk membuat b-roll. Setiap tools punya batas pemakaian sendiri, dan hasilnya perlu kamu cek dulu sebelum dipakai.
        

      


      

        
4. Mode Offline vs AI

        

          Offline: template dasar, langsung jalan tanpa akun apa pun. Mode AI: hasil lebih bervariasi, butuh API key Gemini gratis dari Google (cara membuatnya ada di tab Koneksi AI). Key disimpan di browser kamu sendiri, jangan dibagikan ke siapa pun.
        

      


      

        
5. Kalau Muncul Error

        

          429 = kuota gratis harian habis, coba lagi besok. 503 = server Google sedang sibuk, tunggu beberapa menit lalu coba lagi. Hindari menekan tombol berkali-kali karena setiap klik memakai kuota. Cek panel abu-abu di tab Koneksi AI untuk melihat detail error.
        

      


      

        
6. Hasil = Draf

        

          Edit dulu sebelum posting supaya sesuai gaya dan pengalamanmu. Jangan pakai klaim penghasilan atau hasil pasti, jangan karang testimoni, dan jangan buat stok terbatas palsu.
